# Meta Advertising Campaign Performance Analysis

## Project Overview

Performed a marketing analytics project to evaluate Meta advertising campaign performance across different industries and advertisement formats using Microsoft Excel.

## Project Context

This analysis was developed as part of my marketing internship experience. The dataset included in this repository is **synthetic data created for academic and portfolio purposes** and does not contain any confidential, proprietary, or client information.

## Objective

- Compare campaign performance across industries
- Analyse the effectiveness of different advertisement formats
- Evaluate key marketing performance metrics
- Identify performance trends and generate business insights

## Tools & Techniques

- Microsoft Excel
- Data Cleaning
- Descriptive Statistics
- Pivot Tables
- Pivot Charts
- Data Visualization

## Key Metrics

- Reach
- Impressions
- CTR
- CPC
- CPM
- Conversions

## Analysis

The project involved comparing campaign performance across industries and advertisement formats using key marketing metrics. Excel Pivot Tables and Pivot Charts were used to summarize, compare, and visualize the results.

## Key Insights

- Campaign performance varied across different industries.
- Advertisement formats showed differences in engagement and conversion performance.
- Comparative analysis helped identify high-performing industries and advertisement formats.
- The analysis generated insights to support data-driven marketing decisions.

Excel | Data Analysis | Data Visualization | Marketing Analytics | Business Insights | Comparative Analysis
